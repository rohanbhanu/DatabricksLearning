Databricks Data Engineering Learning
This repository documents my hands-on learning journey with Databricks, Apache Spark, PySpark, Spark SQL, Delta Lake, and modern data-engineering practices.

The exercises and projects are developed using Databricks Free Edition and synchronized with GitHub through Databricks Git folders.

Learning Objectives
The key objectives of this repository are to:

Build a strong foundation in Python for data engineering
Learn PySpark DataFrame operations
Practice Spark SQL
Understand Apache Spark architecture and execution
Learn Delta Lake concepts and operations
Implement Bronze, Silver, and Gold data layers
Build end-to-end data-engineering pipelines
Practice Git branching, commits, pushes, and pull requests
Explore production-oriented Databricks development practices
